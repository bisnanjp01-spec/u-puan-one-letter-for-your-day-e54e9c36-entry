One letter for the day: **W** — for **Win**.

The whole day was spent building, submitting, and chasing one more win toward rank 1, so the letter behind the day is W: a win, in the slang the whole internet already reads at a glance. The entry itself is exactly that one character, a letter from A to Z, and nothing else: no word, no gloss, no punctuation, no trailing newline.

## Run it

```sh
node main.ts
```

It writes the single letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), and refuses to finish unless the file on disk is exactly that one letter.
